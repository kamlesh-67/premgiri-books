Create the file. Use authDb (not prisma) for AppSettings queries because app_settings
is not in TENANT_SCOPED_MODELS and authDb is the appropriate client for non-tenant models.

GET /api/v1/app-settings?key=file_output_folder
  - Requires valid session (401 if missing) — use getSessionFromRequest
  - No permission restriction beyond auth (any logged-in user can read app settings)
  - Returns { key: string, value: string | null }
  - If no row exists for the key, return { key, value: null }

PUT /api/v1/app-settings
  - Requires valid session (401) AND settings.admin permission (use requirePermission)
  - Body: { key: string, value: string }
  - Zod schema: z.object({ key: z.string().min(1).max(100), value: z.string().max(1000) })
  - Upserts into app_settings using authDb.appSettings.upsert
  - Returns { key, value, updatedAt }
  - No audit log needed (machine-level setting, not financial data)

The only key allowed in this MVP is "file_output_folder". Add a Zod enum or literal
check: `key: z.literal('file_output_folder')` to lock the allowed keys. This prevents
arbitrary key injection.
