<objective>
Remove cloud packages from package.json and delete the Inngest API route.

Purpose: CLOUD-06 requires the app to start without cloud env vars present. Even with
no-op stubs, if the packages are still installed they may crash on import when env vars
are absent (e.g. @upstash/redis reads UPSTASH_REDIS_REST_URL at import time). Removing
the packages prevents any startup-time env var validation errors.

Output:
- package.json with 7 cloud packages removed from dependencies
- app/api/inngest/route.ts deleted (or replaced with 410 Gone stub)
</objective>
