    - z from 'zod'
    - authDb from '@/lib/authDb'
    - signJWT from '@/lib/jwt'
    - ACCOUNT_GROUPS from '@/prisma/seed'

    Zod schema named setupSchema:
    - companyName: z.string().min(1).max(200)
    - gstin: z.string().regex(/^[0-9]{2}[A-Z]{5}[0-9]{4}[A-Z]{1}[1-9A-Z]{1}Z[0-9A-Z]{1}$/).optional().or(z.literal(''))
    - pan: z.string().regex(/^[A-Z]{5}[0-9]{4}[A-Z]{1}$/).optional().or(z.literal(''))
    - address: z.string().max(500).optional()
    - stateCode: z.string().length(2)
    - fyStart: z.number().int().min(1).max(12).default(4)
    - adminPassword: z.string().min(8)

    POST handler logic (in order):
    1. REPLAY GUARD: call authDb.company.count(); if count > 0 return NextResponse.json({ error: 'Setup already complete' }, { status: 409 })
    2. JSON PARSE: try request.json() / catch → 400 (same as login route)
    3. ZOD PARSE: setupSchema.safeParse(body); if !success → 400 with parsed.error.flatten()
    4. HASH: const passwordHash = await bcrypt.hash(adminPassword, 12)
    5. TRANSACTION: authDb.$transaction(async (tx) => { ... }) containing in this order:
       a. tx.company.create({ data: { name: companyName, gstin: gstin || null, pan: pan || null, address: address ?? null, stateCode, fyStart } })
       b. tx.role.create({ data: { companyId: company.id, name: 'Owner', permissions: {} } })
       c. tx.accountGroup.createMany({ data: ACCOUNT_GROUPS.map(g => ({ companyId: company.id, name: g.name, nature: g.nature as 'ASSET' | 'LIABILITY' | 'INCOME' | 'EXPENSE', affectsGP: g.affectsGP, isSystem: true })) })
       d. tx.user.create({ data: { companyId: company.id, name: 'Administrator', email: 'admin@premgiribooks.com', passwordHash, roleId: ownerRole.id, isActive: true } })
       e. return { company, ownerRole, user }
    6. JWT: signJWT({ userId: result.user.id, companyId: result.company.id, roleId: result.ownerRole.id, role: 'Owner', uiMode: 'simple', permissions: {} })
    7. COOKIE: response.cookies.set('auth-token', token, { httpOnly: true, sameSite: 'lax', path: '/', maxAge: 60 * 60 * 24 * 7 }) — identical to login route
    8. Return NextResponse.json({ ok: true }) with the cookie set

    Critical notes:
    - Use authDb (NOT prisma) for the entire transaction — prisma has a tenant-scope guard that will throw TenantScopeError on user.create before a session exists
    - The nature cast `g.nature as 'ASSET' | 'LIABILITY' | 'INCOME' | 'EXPENSE'` is required because seed.ts types nature as string, not the Prisma AccountNature enum
    - adminPassword field must NOT be stored anywhere except as bcrypt hash — the raw string must not appear in the DB write
