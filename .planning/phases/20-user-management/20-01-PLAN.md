<objective>
Fix the permissions infrastructure that is currently broken for all roles — the Owner role is
created with `permissions: {}` in the setup route (line 132) and the JWT is also signed with
`permissions: {}` (line 177), which causes every `usePermission()` call and every
`hasPermission()` check to return false for Owner users. This blocks the "Add Team Member"
button, deactivate controls, and the Users nav item from appearing even for Owner.

Purpose: Without correct permissions in the JWT, no User Management UI works. This is the
foundational fix that must land before any other Phase 20 work.

Output: setup route creates Owner role with correct permissions JSON; JWT signed after setup
carries those permissions; /api/v1/auth/me returns permissions; AppSidebar is wired to receive
them from layout.
</objective>
