## Key Decisions & Gotchas (carry forward)

| Decision | Rule |
|----------|------|
| FY utilities | `getFYStart(fy)` + `getFYEnd(fy)` separately — `getFYRange()` DOES NOT EXIST |
| formatINR | Always `@/lib/utils/format` — never `@/lib/format` (two files exist) |
| Component imports | Use `components/primitives/` — all existing pages use primitives, not `components/shared/` |
| Outstanding | Query `prisma.billRef` only — never `voucherEntry.groupBy` |
| Financial arithmetic | Always `decimal.js` — never JS `+` on Decimal values |
| Multi-tenant | `companyId` ALWAYS from `session.user.companyId` — never from request body/URL |
| Soft delete | Vouchers → `status: 'CANCELLED'`; Masters → `isActive: false` |
| Audit log | Every create/update/cancel in same `$transaction` as the data change |
| Indian format | All currency: `₹1,23,456.00` lakh system |
